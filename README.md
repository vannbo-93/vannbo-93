## Featured Projects

### [Book Designer Portfolio — Client Project](https://ussainisawi.com)
A portfolio site built for a professional book designer, with a custom admin dashboard to manage all content.

- Animated showcase: a CSS-only 3D spinning book of covers on the homepage, scroll-driven sections with looping videos, and full-size double-page spreads on each book page
- Admin dashboard to manage books, covers, testimonials, FAQ, services, settings, videos and contact messages, with drag-to-reorder and direct uploads to Cloudinary
- **Frontend:** React 19, TypeScript, Vite, Tailwind CSS v4, Motion, Lenis, React Router
- **Backend:** Node.js, Express 5, TypeScript, MongoDB (Mongoose), Cloudinary, JWT auth
- Deployed on Render (static site + API on a subdomain) with a custom domain

**[Live site](https://ussainisawi.com)** · **[Code](https://github.com/vannbo-93/book-portfolio)**

### [E-commerce Store](https://github.com/vannbo-93/E-commerce-1)
A full stack online store with a separate REST API and frontend.

- **Frontend:** React, TypeScript, Vite, Tailwind CSS
- **Backend:** Node.js, Express, TypeScript, MongoDB (Mongoose) on MongoDB Atlas
- Frontend and API deployed as two separate projects on Vercel

**[Live demo](https://ecommerce-shop-eight-sigma.vercel.app/)** · **[Code](https://github.com/vannbo-93/E-commerce-1)**

### [Wadifa — Job Board](https://github.com/vannbo-93/job-board)
A job board with a public site and an admin dashboard, served from one Next.js app.

- Next.js 16 (App Router), TypeScript, Tailwind CSS, shadcn/ui
- Public site and admin dashboard split with route groups and a `proxy.ts` that routes by subdomain
- Dockerized with a multi-stage build and `standalone` output, auto-deployed to DigitalOcean on every push

**[Live demo](https://job-board-production-h3jfh.ondigitalocean.app)** · **[Code](https://github.com/vannbo-93/job-board)**
